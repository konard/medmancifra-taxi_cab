# taxi_cab
Taxi cab

Как выглядит финальный RideService (единый)
RideService
 ├─ searchAddress()       ← поиск адресов (Nominatim)
 ├─ resolve()             ← прямое геокодирование
 ├─ reverseGeocode()      ← обратное геокодирование
 ├─ fetchRoute()          ← OSRM маршрут
 ├─ getCurrentLocation()  ← GPS
 ├─ history               ← история поиска
 ├─ addToHistory()
 ├─ categories            ← Дом / Работа / Избранное
 ├─ getFavoriteRides()    ← логика избранных поездок
 ├─ getRidesByCategory()
 ├─ watchQuickAddresses() ← быстрые адреса (Firebase)
 ├─ addQuickAddress()
 ├─ deleteQuickAddress()

соберём единый, цельный, продакшен‑готовый пассажирский flow, который выглядит и работает как Uber / Яндекс Go.
Мы уже создали отдельные виджеты, теперь я покажу как всё соединяется в один сценарий, чтобы:
    пассажир выбирает точки
    выбирает тариф
    запускается поиск водителя
    водитель найден → ETA + карточка
    водитель едет → анимация прибытия
    поездка началась → DrivingScreen
    поездка завершена → оплата
    после оплаты → оценка
    при желании → отмена поездки
